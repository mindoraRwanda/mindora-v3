## Common Demo Questions & Answers

**Q: Is this just mock data?**  
A: No! All data is real and persists. Create an account, add data, close the app, reopen - everything is still there.

**Q: Can multiple people use it?**  
A: Yes! Each user account has completely isolated data. Create as many accounts as you want.

**Q: Does it work offline?**  
A: Yes! All data is stored locally using AsyncStorage. No internet required.

**Q: How hard is it to connect to a real backend?**  
A: Very easy! Just replace AsyncStorage calls with API calls in AuthContext. The rest of the app stays the same.

**Q: What happens if I logout?**  
A: Your data is saved. Login again and everything is exactly as you left it.
